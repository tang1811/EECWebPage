# งานประกันคุณภาพ

หน้า `/quality-assurance/` รวมเอกสารจริงจากเว็บไซต์เดิม ตรวจสอบเมื่อ 11 กันยายน 2569

## แหล่งข้อมูล

`http://www.eec.ac/` ใช้ frame แสดง `https://tlc.ac/` ซึ่งเข้าสู่เนื้อหาที่ `https://tlc.ac/main.php`

| หมวด | หน้าเดิม | จำนวน PDF |
| --- | --- | ---: |
| รายงาน SAR และการประกันคุณภาพภายนอก | https://tlc.ac/self_assessment.php | 7 |
| เผยแพร่รายงานการประเมินตนเอง | https://tlc.ac/public_assessment.php | 3 |
| แผนปฏิบัติงานประจำปี | https://tlc.ac/annual_plan.php | 6 |
| มาตรฐานสถานศึกษาและประกาศให้ใช้แผนฯ | https://tlc.ac/educational_standards.php | 7 |
| คู่มือและแนวปฏิบัติ | https://tlc.ac/assurance_load.php | 5 |
| ผลงานปีการศึกษา 2568 | เมนูงานประกันคุณภาพที่ https://tlc.ac/main.php | 1 |

ดาวน์โหลดเพื่อตรวจสอบครบ 29 ไฟล์ ทุกลิงก์ตอบ HTTP 200 มี PDF signature และเปิดด้วย PyMuPDF ได้ จำนวนหน้าและขนาดไฟล์ในข้อมูลมาจากไฟล์ที่อ่านจริง รวมประมาณ 296 MiB

หน้าเว็บเปิด PDF ต้นฉบับจาก `tlc.ac` ในแท็บใหม่ ไม่เก็บ PDF ซ้ำใน Git (แผนปี 2565 มีขนาด 113.9 MB) จึงต้องรักษาไฟล์บนโฮสต์เดิมไว้ หรือย้ายไฟล์ไปโฮสต์เอกสารก่อนปิดเว็บเดิม ภาพหนังสือรับรองใน `public/assets/quality/external-assurance.png` เรนเดอร์จากหน้าแรกของ PDF ต้นฉบับ

## ข้อเท็จจริงที่ใช้

- SAR ที่เว็บเดิมเผยแพร่: 2562–2567 ไม่ได้เพิ่มรายงาน 2568 หรือ 2569 ที่ไม่พบในต้นทาง
- แผนปฏิบัติงาน: 2564–2569
- เอกสารเผยแพร่ SAR: 2564, 2565, 2567
- ประกาศให้ใช้แผนฯ: 2566–2568; ประกาศให้ใช้มาตรฐาน: 2565–2568
- หนังสือรับรอง สมศ. ระบุการประกันคุณภาพภายนอกด้านการอาชีวศึกษา พ.ศ. 2565–2569 ตั้งแต่ 22 สิงหาคม 2565 ออกหนังสือ 22 กันยายน 2565 ใช้ช่วงปีตามหนังสือโดยไม่อนุมานวันหมดอายุ
- PDF ผลงานปี 2568 คือรายงานโครงการ “เครื่องตัดโฟมอัตโนมัติ” จำนวน 48 หน้า
- คู่มือ SAR 2568 เป็นคู่มือการจัดทำรายงาน ไม่ใช่รายงาน SAR ของวิทยาลัยปี 2568

## การปรับข้อมูล

- `src/data/quality-documents.json`: รายชื่อเอกสาร หมวด ปี ลิงก์ต้นฉบับ หน้าแหล่งข้อมูล ขนาดไบต์ และจำนวนหน้า
- `src/data/quality-data.ts`: ชื่อหมวด ลำดับหมวด วันที่ตรวจสอบ และฟังก์ชันแสดงขนาดไฟล์
- `src/pages/quality-assurance.astro`: เนื้อหาหน้าและเอกสารเด่น เลือกฉบับด้วย ID ที่ระบุไว้อย่างชัดเจน
- `src/styles/quality-assurance.css`: รูปแบบหน้า แยกด้วยชื่อคลาส `qa-`

การเปลี่ยนข้อมูลต้อง build ใหม่ หน้าไม่เชื่อม CMS ในรอบนี้ การกรองหมวด ปี และคำค้นทำในเบราว์เซอร์ รองรับลิงก์ `?category=sar&year=2567#documents` และอ่านเอกสารทั้งหมดได้เมื่อปิด JavaScript ช่องปีใช้ปีในชื่อเอกสาร; เอกสารที่ไม่มีปีในชื่ออยู่ในตัวเลือก “ไม่ระบุปี”
