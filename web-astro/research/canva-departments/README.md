# ข้อมูลและภาพจาก Canva แยกตามแผนก

ตรวจเมื่อ 2026-09-14 · [เอกสารต้นทาง](https://www.canva.com/design/DAGD2vsgA_g/HYv35U7NJk1JuDL6CuzJuw/view) · [เปิดรายงานพร้อมภาพ](index.html)

อ่านและตรวจภาพสไลด์ครบ **97 หน้า** แบ่งเป็น **8 แผนก + ปริญญาตรีไฟฟ้า 1 กลุ่ม** และภาพรวมวิทยาลัย

ดาวน์โหลดทรัพยากรภาพได้ **78 ไฟล์** คัดไว้ใช้งาน **68 ไฟล์** เก็บที่ `public/assets/courses/canva/<department>/` ไฟล์ยังคงพิกเซล สัดส่วน และคุณภาพตามที่ตัวอ่าน Canva ให้มา ไม่ใช่การ export ต้นฉบับความละเอียดสูงสุดจากบัญชีเจ้าของงาน

## ข้อค้นพบและสิ่งที่ใช้กับเว็บได้

- นำไปใช้กับเว็บได้ทันทีในงานจัดเนื้อหา: คำอธิบายแผนก ทักษะ ห้องปฏิบัติการ แนวทางอาชีพ และภาพถ่ายที่คัดแล้ว โดยมีเลขหน้าอ้างอิงกำกับ
- ให้ความสำคัญกับหน้าปริญญาตรีไฟฟ้าก่อน: ข้อมูลเว็บยังไม่มีภาพหลัก และหน้าแสดงข้อมูลใช้โครงสร้างร่วมกับ ปวส.; เอกสารมีเนื้อหาเฉพาะหลักสูตรครบหน้า 16–24
- ทวิภาคี: หน้า 20 ระบุชัดเจนสำหรับปริญญาตรีไฟฟ้า แต่ข้อมูลรายการหลักสูตรยังไม่ได้ทำเครื่องหมายให้หลักสูตรนี้ ขณะที่หน้ารายละเอียดแสดงเครื่องหมายทวิภาคีทุกหลักสูตร ควรใช้ข้อมูลรายหลักสูตรชุดเดียวกัน
- ชื่อและระดับที่ต้องเทียบกับทะเบียนหลักสูตรปัจจุบัน: เทคนิคยานยนต์/เทคนิคเครื่องกล, ปวช. โลจิสติกส์ และ ปวส. ธุรกิจดิจิทัล ซึ่งยังไม่ตรงกับรายการบนเว็บ
- เอกสารไม่ครอบคลุมรายละเอียดอิเล็กทรอนิกส์ (ปวช./ปวส.), เครือข่ายคอมพิวเตอร์และความปลอดภัย และเทคนิคอุตสาหกรรม จึงยังใช้ยืนยัน 4 รายการนี้ไม่ได้
- ข้อมูลราคา 62,650 บาท ผ่อน 3 งวด และปรับพื้นฐาน 900 บาท เป็นตัวเลขจากหน้า 22 ไม่มีปีการศึกษาของราคากำกับ จึงเก็บเป็นข้อมูลอ้างอิงก่อน
- รูปแบบภาพ: ใช้ไฟล์ภาพที่แยกออกมาแทนภาพหน้าสไลด์ทั้งหน้า เพื่อวางข้อความ HTML ได้ชัดเจนบนมือถือ; กรอบภาพแต่ละส่วนใช้สัดส่วนเดียวกัน และทดสอบตำแหน่งครอปตามภาพ

### ภาพรวมวิทยาลัย

ใช้ภาพอาคาร บรรยากาศการเรียน และปรัชญาวิทยาลัยประกอบหน้าเกี่ยวกับเรา พร้อมใช้ข้อมูลวุฒิสมัครเรียนในหน้ารับสมัคร

**ข้อมูลอ้างอิง**

- ปรัชญาเน้นคนดี ระเบียบวินัย เทคโนโลยี ทักษะฝีมือ และคุณธรรม ([หน้า 2](https://www.canva.com/design/DAGD2vsgA_g/HYv35U7NJk1JuDL6CuzJuw/view#2))
- ปวช. รับผู้จบ ม.3; ปวส. ระบุผู้จบ ปวช. สายตรง หรือ ม.6/เทียบเท่า ([หน้า 3](https://www.canva.com/design/DAGD2vsgA_g/HYv35U7NJk1JuDL6CuzJuw/view#3))
- หน้า 4–9 แนะนำ 4 แผนกอุตสาหกรรม; หน้า 10–15 แนะนำบัญชี ธุรกิจดิจิทัล โลจิสติกส์ และกราฟิก ([หน้า 4](https://www.canva.com/design/DAGD2vsgA_g/HYv35U7NJk1JuDL6CuzJuw/view#4), [หน้า 10](https://www.canva.com/design/DAGD2vsgA_g/HYv35U7NJk1JuDL6CuzJuw/view#10))
- เอกสารระบุ www.eec.ac และโทรศัพท์ 038 494 066 ในหน้าปิดแผนก ([หน้า 2](https://www.canva.com/design/DAGD2vsgA_g/HYv35U7NJk1JuDL6CuzJuw/view#2), [หน้า 24](https://www.canva.com/design/DAGD2vsgA_g/HYv35U7NJk1JuDL6CuzJuw/view#24), [หน้า 33](https://www.canva.com/design/DAGD2vsgA_g/HYv35U7NJk1JuDL6CuzJuw/view#33), [หน้า 96](https://www.canva.com/design/DAGD2vsgA_g/HYv35U7NJk1JuDL6CuzJuw/view#96))

**ใช้กับเว็บ:**

- เติมภาพสถานที่จริงในหน้าเกี่ยวกับเรา
- ใช้ภาพถ่ายแผนกบนการ์ดหลักสูตรหน้าแรก ซึ่งยังจำกัดไว้สูงสุด 10 หลักสูตร
- ทำคำตอบเรื่องวุฒิสมัครเรียนในหน้ารับสมัครจากข้อมูลหน้า 3

**ข้อมูลที่ต้องเทียบเพิ่ม:**

- ใช้สีเขียวและสีรองของเว็บไซต์เดิม; สีประจำสไลด์ใช้เป็นข้อมูลประกอบ ไม่เปลี่ยนสีหลักเว็บ
- หน้า 4–15 เป็นภาพรวมและสไลด์ขยายรายแผนก ไม่ใช่หลักสูตรใหม่ทุกหน้า
- หน้า 97 เป็นหน้าปิด/ช่องทางติดตาม ไม่มีเนื้อหาหลักสูตรเพิ่ม

### ปริญญาตรี เทคโนโลยีไฟฟ้า (ต่อเนื่อง)

หลักสูตรต่อเนื่องสำหรับผู้จบ ปวส. สายที่เกี่ยวข้องและผู้ทำงานแล้ว เนื้อหาครอบคลุมระบบไฟฟ้าอุตสาหกรรม ระบบควบคุม และการจัดการพลังงาน

**ข้อมูลอ้างอิง**

- วุฒิสมัคร: ปวส. ที่เกี่ยวข้องกับไฟฟ้า อิเล็กทรอนิกส์ หรือเครื่องกลไฟฟ้า ([หน้า 19](https://www.canva.com/design/DAGD2vsgA_g/HYv35U7NJk1JuDL6CuzJuw/view#19))
- ระยะเวลา 2 ปี และระบุเรียนเสาร์–อาทิตย์ เหมาะกับผู้มีงานประจำ ([หน้า 24](https://www.canva.com/design/DAGD2vsgA_g/HYv35U7NJk1JuDL6CuzJuw/view#24))
- ปีแรกเรียนทฤษฎีและปฏิบัติ ปีที่ 2 ฝึกงานในสถานประกอบการแบบทวิภาคี ([หน้า 20](https://www.canva.com/design/DAGD2vsgA_g/HYv35U7NJk1JuDL6CuzJuw/view#20))
- เอกสารระบุค่าเรียนตลอดหลักสูตร 62,650 บาท ผ่อน 3 งวด และปรับพื้นฐานเพิ่ม 900 บาทหากต้องเรียน ([หน้า 22](https://www.canva.com/design/DAGD2vsgA_g/HYv35U7NJk1JuDL6CuzJuw/view#22))

**ทักษะ:** ระบบไฟฟ้าอุตสาหกรรมและระบบควบคุม / Motor Control, PLC และ Inverter / การจัดการพลังงานและประสิทธิภาพการใช้พลังงาน / ติดตั้ง ทดสอบ และควบคุมเครื่องกลไฟฟ้าอย่างปลอดภัย ([หน้า 20](https://www.canva.com/design/DAGD2vsgA_g/HYv35U7NJk1JuDL6CuzJuw/view#20))

**ห้องและอุปกรณ์:** ห้องทดสอบระบบ PLC / ห้องทดสอบการติดตั้งเครื่องปรับอากาศ / ห้องปฏิบัติการติดตั้งไฟฟ้าภายในอาคาร ([หน้า 21](https://www.canva.com/design/DAGD2vsgA_g/HYv35U7NJk1JuDL6CuzJuw/view#21))

**แนวทางอาชีพ:** ช่างควบคุมระบบไฟฟ้า / เจ้าหน้าที่ระบบควบคุมอัตโนมัติ / ช่างซ่อมบำรุงเครื่องจักรไฟฟ้า / เจ้าหน้าที่ระบบพลังงาน / ช่างติดตั้งระบบไฟฟ้า ([หน้า 23](https://www.canva.com/design/DAGD2vsgA_g/HYv35U7NJk1JuDL6CuzJuw/view#23))

**ใช้กับเว็บ:**

- เติมภาพหลักและแกลเลอรีให้ pt-electrical ซึ่งยังไม่มีภาพหลักในข้อมูลหลักสูตร
- เพิ่มรายละเอียดรูปแบบเรียนเสาร์–อาทิตย์และแผนเรียน 2 ปี
- ใช้หน้า 20 เป็นแหล่งอ้างอิงสถานะทวิภาคีของหลักสูตรนี้

**ข้อมูลที่ต้องเทียบเพิ่ม:**

- ราคาและรอบเรียนไม่มีปีการศึกษากำกับในสไลด์ ต้องเทียบประกาศรับสมัครปัจจุบันก่อนแสดงเป็นข้อเสนอที่เปิดรับ
- ข้อมูลหน้า 20 เป็นของปริญญาตรี ไม่ควรยกไปยืนยันรูปแบบทวิภาคีของ ปวช./ปวส.
- หน้าเว็บรายละเอียดใช้ข้อมูลหน่วยกิตและชื่อระดับร่วมกับ ปวส. อยู่ ควรแยกข้อมูลของปริญญาตรี

### ช่างยนต์ / เทคนิคยานยนต์

เรียนรู้เครื่องยนต์และระบบไฟฟ้ายานยนต์ผ่านการซ่อมบำรุง ถอดประกอบ และตรวจวิเคราะห์ โดยมีสถานีฝึกเครื่องยนต์ ยาง ช่วงล่าง และรถจักรยานยนต์

**ข้อมูลอ้างอิง**

- เอกสารใช้ชื่อ ปวช. ช่างยนต์ และ ปวส. เทคนิคยานยนต์ ([หน้า 28](https://www.canva.com/design/DAGD2vsgA_g/HYv35U7NJk1JuDL6CuzJuw/view#28))
- ปวช. 3 ปี ปวส. 2 ปี เรียนทั้งทฤษฎีและปฏิบัติ ([หน้า 29](https://www.canva.com/design/DAGD2vsgA_g/HYv35U7NJk1JuDL6CuzJuw/view#29))

**ทักษะ:** ซ่อมบำรุงและประกอบเครื่องยนต์ / ระบบไฟฟ้ายานยนต์ / ตรวจวิเคราะห์เครื่องยนต์ดีเซลและคอมมอนเรล / งานบริการยาง ช่วงล่าง และรถจักรยานยนต์ ([หน้า 29](https://www.canva.com/design/DAGD2vsgA_g/HYv35U7NJk1JuDL6CuzJuw/view#29), [หน้า 30](https://www.canva.com/design/DAGD2vsgA_g/HYv35U7NJk1JuDL6CuzJuw/view#30), [หน้า 31](https://www.canva.com/design/DAGD2vsgA_g/HYv35U7NJk1JuDL6CuzJuw/view#31))

**ห้องและอุปกรณ์:** เครื่องยนต์คอมมอนเรล / ตรวจวิเคราะห์และถอดประกอบเครื่องยนต์ดีเซล / สถานีเปลี่ยนยางและถ่วงล้อ / สถานีรถจักรยานยนต์ / สถานีตรวจช่วงล่าง / สถานีถอดประกอบเครื่องยนต์จักรยานยนต์และเครื่องยนต์เล็กแก๊สโซลีน ([หน้า 30](https://www.canva.com/design/DAGD2vsgA_g/HYv35U7NJk1JuDL6CuzJuw/view#30), [หน้า 31](https://www.canva.com/design/DAGD2vsgA_g/HYv35U7NJk1JuDL6CuzJuw/view#31))

**แนวทางอาชีพ:** ช่างซ่อมบำรุงยานยนต์ / ช่างเทคนิคยานยนต์ / งานศูนย์บริการ / พนักงานขายและบริการลูกค้าด้านยานยนต์ ([หน้า 32](https://www.canva.com/design/DAGD2vsgA_g/HYv35U7NJk1JuDL6CuzJuw/view#32))

**ใช้กับเว็บ:**

- ใช้ภาพการฝึกกับรถจริงเป็นภาพหลักของ yon และภาพประกอบ ps-mech
- เพิ่มแกลเลอรีพร้อมชื่อสถานีฝึกที่ตรวจจากหน้า 30–31
- เขียนรายละเอียดวิชาให้เน้นการลงมือทำตามภาพและเนื้อหาในสไลด์

**ข้อมูลที่ต้องเทียบเพิ่ม:**

- ชื่อ ปวส. ในเว็บคือเทคนิคเครื่องกล แต่เอกสารใช้เทคนิคยานยนต์ ควรเทียบชื่อหลักสูตรปัจจุบันก่อนเปลี่ยนชื่อ
- เอกสารชุดนี้ยังไม่ยืนยันรายละเอียด EV/Hybrid ที่เว็บระบุ
- แยกอาชีพเริ่มต้นออกจากเส้นทางต่อยอด เช่น วิศวกรยานยนต์ ไม่เสนอว่าจบทุกระดับแล้วได้ตำแหน่งนั้นทันที

### ช่างไฟฟ้ากำลัง / ไฟฟ้า

ฝึกติดตั้งและซ่อมบำรุงระบบไฟฟ้า เครื่องปรับอากาศ และระบบควบคุมเครื่องกลไฟฟ้า โดยเน้นความปลอดภัยและการใช้งานจริง

**ข้อมูลอ้างอิง**

- ระบุเปิดสอนระดับ ปวช. และ ปวส. ด้านไฟฟ้ากำลัง ([หน้า 37](https://www.canva.com/design/DAGD2vsgA_g/HYv35U7NJk1JuDL6CuzJuw/view#37))
