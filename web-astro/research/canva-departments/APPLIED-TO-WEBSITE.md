# การนำข้อมูลไปใช้ในหน้ารายละเอียดหลักสูตร

อัปเดตล่าสุด 14 กันยายน 2569: ผู้ใช้สั่งปิด `electronic`, `ps-electronic`, `ps-network`, `ps-industrial` แล้ว ตั้ง `enabled: false` และใช้รายการหลักสูตรกลางกับหน้าแรก เมนู รายการแนะนำ และ sitemap ปัจจุบันแสดง **15 หลักสูตร**, URL ทั้ง 4 คืน **404**, Build ล่าสุดผ่าน **45 หน้า** และหน้ารวมหลักสูตรไม่มี banner ด้านบน ส่วนรายละเอียด/ผลตรวจ 19 หลักสูตรและ 49 หน้าในบันทึกด้านล่างเป็นขั้นก่อนปิด 4 หน้า เนื้อหาและไฟล์เดิมยังเก็บไว้สำหรับเปิดกลับเมื่อผู้ใช้สั่ง

ปรับเมื่อ 14 กันยายน 2569 ในเว็บที่รันบนเครื่อง ยังไม่ได้ Deploy

## การตัดสินใจด้านข้อมูล

- แยกทักษะ ปวช. ช่างกลโรงงาน และ ปวส. เทคนิคการผลิตตามความแตกต่างที่หน้า 52 ไม่สร้างความต่างระหว่างระดับขึ้นเองสำหรับแผนกอื่นที่เอกสารอธิบายรวมกัน
- แยกปริญญาตรีต่อเนื่องจาก ปวส. แสดง 2 ปี เรียนเสาร์–อาทิตย์ ปีแรกทฤษฎี/ปฏิบัติ และปีที่ 2 ทวิภาคี พร้อมวุฒิเข้าเรียนสายที่เกี่ยวข้อง
- ค่าใช้จ่ายปริญญาตรี 62,650 บาท แบ่ง 3 งวด และปรับพื้นฐานเพิ่ม 900 บาท แสดงพร้อมคำอธิบายว่าต้นทางไม่มีปีการศึกษากำกับ และให้สอบถามค่าใช้จ่ายรอบปัจจุบัน ไม่ใช้เป็นประกาศเปิดรับสมัครหรือราคาโปรโมชั่น
- เพิ่มสถานะทวิภาคีให้ `pt-electrical` จากหน้า 20 ป้ายเดิมของ `yon`, `faifaa`, `mecha`, `ps-logistics` ยังคงอ้างอิงข้อมูลตารางหลักสูตรเดิมของเว็บไซต์ ไม่ถือว่า Canva ยืนยันหรือปฏิเสธสถานะเหล่านี้ ไม่แสดงทวิภาคีเหมารวมทุกหลักสูตร
- รักษาชื่อในทะเบียนหลักสูตรเว็บไซต์ `ps-mech` = เทคนิคเครื่องกล และ `ps-electrical` = ไฟฟ้า พร้อมแสดงชื่อที่ต่างกันในเอกสารเป็นข้อมูลประกอบบนหน้าหลักสูตร (เทคนิคยานยนต์ / ช่างไฟฟ้ากำลัง) จนกว่าจะมีชื่อทางการของรอบรับสมัครปัจจุบัน URLs เดิมยังใช้ได้
- ไม่เพิ่ม ปวช. โลจิสติกส์ หรือ ปวส. ธุรกิจดิจิทัลเป็นหลักสูตรเปิดรับใหม่จากเอกสารเพียงชุดเดียว
- `electronic`, `ps-electronic`, `ps-network`, `ps-industrial` ไม่มีข้อมูลแผนกตรงในเอกสาร คงรายละเอียดเฉพาะสาขาเดิมไว้ ไม่ใช้เนื้อหาหรือภาพจากแผนกใกล้เคียงไปยืนยันแทน
- เอาชุดหน่วยกิตที่เคยใช้เหมารวม ข้อความรับประกันงาน/ติดต่อกลับ และวันที่อัปโหลดวิดีโอที่ใส่ไว้ตายตัวออกจากหน้ารายละเอียดหลักสูตร
- หน้ารายละเอียดอ่านได้โดยไม่รอ JavaScript ใช้การเลื่อนหน้าปกติ แกลเลอรีกดดูภาพเต็มได้ และลิงก์ภาพยังทำงานเมื่อปิด JavaScript
- ยกเลิกหน้า scroll-preview และ dependency motion ของตัวอย่างที่ไม่ได้ใช้ ข้อมูลวิจัยและภาพที่ดาวน์โหลดเก็บไว้ทั้งหมด
- หน้ารวมหลักสูตรนับจำนวนจากข้อมูลจริง 19 หลักสูตร ตัวกรองระดับ/ประเภท/ทวิภาคีใช้ข้อมูลชุดเดียวกัน ระบบสมัครออนไลน์ยังปิดตามค่าตั้งเดิม และปุ่มภายในหน้าหลักสูตรพาไปสอบถามวิทยาลัย

## การตรวจสอบ

- Build สำเร็จ 49 หน้า และตรวจ TypeScript ในไฟล์ที่เกี่ยวข้องผ่าน
- ตรวจทั้ง 19 หน้าที่ 1440px และ 390px: ภาพโหลดได้ ไม่มีข้อความทับภาพ ไม่มี horizontal overflow และเนื้อหาไม่ถูกซ่อนก่อนเลื่อน
- ตรวจภาพเต็มด้วยปุ่มลูกศร / Escape และการคืน focus ให้รูปต้นทาง รวมถึงการคืนการเลื่อนหลังปิดภาพ
- ตรวจตัวกรองทวิภาคี 5 รายการ (4 รายการจากตารางเดิม + ปริญญาตรีที่ยืนยันเพิ่มเติม) และการใช้ร่วมกับตัวกรองระดับ
- ตรวจหน้าปริญญาตรีเมื่อปิด JavaScript: ข้อมูล ภาพ ค่าใช้จ่าย และลิงก์ภาพยังใช้งานได้
- หลักฐานการตรวจและภาพหน้าจอเก็บใน `.astro/mobile-home-qa/department-*` ซึ่งเป็นไฟล์ตรวจงานภายในที่ไม่ได้เผยแพร่

## อัปเดตเพิ่มเติม 2026-09-14 — About และสีประจำแผนก

ข้อมูลจำนวน 19 หลักสูตร / build 49 หน้าในส่วนก่อนหน้าเป็นผลก่อนผู้ใช้สั่งปิด 4 หน้า ปัจจุบัน `electronic`, `ps-electronic`, `ps-network`, `ps-industrial` ตั้ง `enabled: false` และไม่สร้างหน้า เหลือ 15 หลักสูตรบนเว็บไซต์และ build 45 หน้า ข้อมูลต้นทางและภาพยังเก็บไว้ครบ

- หน้า `/about/` เพิ่มภาพอาคารจากหน้า 2/97, ปรัชญา 5 ข้อ, 3 ระดับการเรียน, การเรียนทฤษฎีควบคู่ปฏิบัติ, ห้องปฏิบัติการและชุดฝึก 8 แผนก และปริญญาตรีต่อเนื่องสำหรับคนทำงานจากหน้า 19–24
